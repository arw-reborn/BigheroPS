# 🎮 BigHero PS — Galaxy Control

Sistem monitoring & kontrol rental PS berbasis web (PWA) untuk BigHero PS.

---

## 🚀 Deploy ke GitHub Pages

### 1. Buat Repository GitHub
1. Login ke [github.com](https://github.com)
2. Klik **New repository**
3. Nama repo: `bighero-ps` (atau apapun)
4. Set **Public**
5. Klik **Create repository**

### 2. Upload Files
Upload semua file ini ke repo:
```
index.html
manifest.json
sw.js
favicon.ico
icons/
  ├── icon-72x72.png
  ├── icon-96x96.png
  ├── icon-128x128.png
  ├── icon-144x144.png
  ├── icon-152x152.png
  ├── icon-192x192.png
  ├── icon-384x384.png
  ├── icon-512x512.png
  ├── apple-touch-icon.png
  ├── favicon-32x32.png
  └── favicon-16x16.png
```

### 3. Aktifkan GitHub Pages
1. Buka **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / root
4. Klik **Save**
5. URL akan jadi: `https://USERNAME.github.io/REPO-NAME/`

---

## 📱 Install ke HP (Android)

1. Buka URL GitHub Pages di **Chrome**
2. Tunggu banner "INSTALL BIGHERO PS" muncul di bawah
3. Tap **INSTALL** — app langsung masuk ke home screen!

Atau manual: Chrome menu (⋮) → **Add to Home screen**

## 📱 Install ke HP (iPhone/iOS)

1. Buka URL di **Safari**
2. Tap tombol Share (⬆️)
3. Pilih **Add to Home Screen**
4. Tap **Add**
